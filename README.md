# StudentBSU

iOS-приложение для студентов факультета РФиКТ БГУ. Интегрируется с личным кабинетом (student.bsu.by), агрегирует расписание и данные об успеваемости.

## Функционал

*   **Расписание**: парсинг и отображение пар, фильтрация по подгруппам, офлайн-режим.
*   **Экзамены**: парсинг текущих и прошлых оценок из личного кабинета, автоматическое слияние с расписанием сессии (даты, время, аудитории) через Firebase.
*   **Заметки**: менеджер записей.
*   **Дедлайны**: локальный трекер задач.
*   **Профиль**: авторизация на портале БГУ, вывод информации о студенте и общежитии.

## Стек технологий

*   **Язык**: Swift 5
*   **UI**: Programmatic UIKit (без Storyboards)
*   **Асинхронность**: async/await
*   **Сеть и парсинг**: URLSession, SwiftSoup
*   **Локальное хранилище**: Core Data, UserDefaults, FileManager (кэш)
*   **Backend**: Firebase (Remote Config, Storage)
*   **Архитектура**: Feature-based MVC/MVVM

## Запуск проекта

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/DanielRaze/StudentBSU.git
   ```
2. Для работы приложения необходим конфигурационный файл Firebase. Положите актуальный `GoogleService-Info.plist` в папку `StudentBSU/` (файл добавлен в `.gitignore`).
3. Откройте проект в Xcode и дождитесь разрешения зависимостей SPM.
4. Соберите проект.
